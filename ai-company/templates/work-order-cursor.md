# 作業指示書テンプレ — Cursor（Claude Code経由）

対象プロジェクト：**おのくん4コマ / X・SNS投稿 / AIスタイル診断**

つばさはこの型で指示書を出力する。hayator はこれを Cursor に貼る。

```
【担当ツール】Cursor（Claude Code）
【プロジェクト】（おのくん4コマ / X・SNS投稿 / AIスタイル診断 のどれか）
【ゴール】（例：おのくん4コマを1本、ネーム→作画指示まで作る）
【前提・入力】
  - 参照する既存ファイル / フォルダ：
  - 素材・トーン・過去作の傾向：
【要件】
  - （箇条書き。例：起承転結／登場：おのくん／オチはポジティブ）
  - ネガティブ表現は使わない
【成果物】
  - （例：script.md（4コマ台本）＋作画指示、または投稿文＋ハッシュタグ）
【完了条件(DoD)】
  - （例：4コマ台本＋SNS投稿文＋画像プロンプトが揃っている）
【報告先】つばさへ：成果物のパス/本文・詰まった点
```

## 注意
- SNS投稿は**下書きまで**。実際の投稿前に hayator が最終確認する
- ネガティブ表現禁止（レボの設計大原則）
