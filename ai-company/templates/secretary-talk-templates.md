# つばさ会話テンプレート集（日常秘書業務用）

> 参考：AIエージェント構築の定石「状況 → 依頼 → 出力形式」の3点セット（note記事 2025-11-15 より導入）
> 使い方：下のテンプレをコピーして、【 】内だけ書き換えて つばさに送る。
> 育て方：**うまくいった指示は、その場でこのファイルに追加する**（全社ルール第10条）。

---

## 1. 予定登録

```
【状況】新しい予定が決まった
【依頼】カレンダーに登録して
　・用件：◯◯さんと打ち合わせ
　・日時：◯月◯日 ◯時〜（終了未定なら1時間で）
【出力】登録結果を「件名・日時・場所」で報告。接続不安定なら .ics で
```

## 2. 今日の予定・タスク確認

```
【状況】朝、今日の動きを把握したい
【依頼】今日の予定と、期限が近いタスクをまとめて
【出力】時系列で箇条書き。移動や準備が必要なものには一言メモ
```

## 3. メール返信の下書き

```
【状況】◯◯さんから問い合わせ／依頼のメールが来た（本文を貼る）
【依頼】丁寧な返信文を作って
　・回答すること：◯◯
　・提案すること：次のアクション
【出力】件名＋本文。送信はしない（私が確認して送る）
```

## 4. リサーチ依頼

```
【状況】◯◯について判断したい
【依頼】事実ベースで調べて
　・特に知りたい点：◯◯
　・用途：企画書に使う／判断材料にする
【出力】要点を見出し付きで、出典URL付き。推測は「推測」と明記
```

## 5. 企画書・文書のたたき台

```
【状況】◯◯向けの企画書（案内文・投稿文）が必要
【依頼】たたき台を作って
　・伝えたい核：◯◯
　・トーン：前向き・押しつけない・ネガ表現なし
【出力】PDF化できるMarkdownで。構成→本文の順
```

## 6. 作業の割り振り（司令塔）

```
【状況】◯◯（プロジェクト名）で「◯◯したい」
【依頼】どの担当ツール（Cursor/codex/エルメスGrok/Claude Code）の仕事か判定して、
　　　　作業指示書を作って
【出力】担当ツール名＋貼るだけの作業指示書
```

## 7. 日報・作業ログまとめ

```
【状況】今日やったことを記録したい（箇条書きで貼る）
【依頼】整理して作業ログに追記して
【出力】worklog形式（日付・担当・内容・結果）＋明日への申し送りがあれば一言
```

---

## テンプレを増やすルール（育て方）

1. 同じ形の指示を**2回**出したら、それはテンプレ化のサイン
2. うまくいった指示文をこのファイルの一番下に追加（つばさに「これテンプレにして」でもOK）
3. 失敗した指示は、原因（曖昧だった点）を直してから登録する
