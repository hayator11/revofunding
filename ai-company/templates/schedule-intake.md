# まとめ入力テンプレ — 予定（スケジュール）

「毎回1件ずつ登録が面倒」を解消するための、まとめ入力フォーマット。
hayator はこの形で**箇条書きで一気に**渡す。つばさが一括処理する。

## 入力形式

```
日付 開始時刻[-終了時刻] 件名 [/ 場所] [/ メモ]
```

### 例
```
7/15 17:30 タケウチさんMTG
7/16 21:00-22:00 ぎんサロ / Zoom
8/10 10:57-11:30 空の駅 下見対応 / 空の駅おのくんの実家 / 読売旅行 森田様2名
```

## つばさの処理ルール
- 対象カレンダーは **hayator（ishishinokai@gmail.com）**
- 終了時刻の指定がなければ **1時間**
- タイムゾーンは **Asia/Tokyo**
- 登録手段：
  - **claude.ai（秘書つばさ）** … カレンダーに直接登録（推奨・主戦場）
  - **Claude Code しか使えない時** … 複数予定を**1つの .ics にまとめて**渡す（タップ回数削減）
- 登録後は「件名・日時・（あれば）リンク」を一覧で報告
