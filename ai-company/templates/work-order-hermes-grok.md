# 作業指示書テンプレ — エルメスエージェント（Grok経由）

対象プロジェクト：**レボリンク**

つばさはこの型で指示書を出力する。hayator はこれをエルメスエージェントに貼る。

```
【担当ツール】エルメスエージェント（Grok）
【プロジェクト】レボリンク
【ゴール】（例：レボリンクの◯◯機能の下書き/検討を作る）
【前提・入力】
  - 参照する情報・URL・過去の方針：
  - Grok の強みを活かす点（リアルタイム情報・X連携など）：
【要件】
  - （箇条書き）
  - ネガティブ表現は使わない
【成果物】
  - （例：企画メモ / 投稿案 / 調査結果）
【完了条件(DoD)】
  - （例：意思決定に使える形でまとまっている）
【報告先】つばさへ：成果物・詰まった点
```
