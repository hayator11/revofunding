# 作業指示書テンプレ — codex（Codex）

対象プロジェクト：**レボファンディング / レボリスト診断**

つばさはこの型で指示書を出力する。hayator はこれを codex に貼る。

```
【担当ツール】codex（Codex）
【プロジェクト】（レボファンディング / レボリスト診断）
【ゴール】（例：フィードバック送信先を Formspree で実装する）
【前提・入力】
  - 対象リポジトリ / ブランチ：
  - 触ってよいファイル / 触らないファイル：
  - 参照仕様（CLAUDE.md の該当箇所など）：
【要件】
  - （箇条書きの実装要件）
  - 各リポの CLAUDE.md を厳守／プロジェクトをまたいだ編集はしない
  - ネガティブ表現は使わない（診断コピー含む）
【成果物】
  - （例：変更ファイル一覧 ＋ 動作確認結果 ＋ コミット）
【完了条件(DoD)】
  - （例：ローカルで動作確認済み・指定ブランチにコミット）
【報告先】つばさへ：変更概要・コミット/PRリンク・詰まった点
```

## 注意
- **プロジェクトをまたいだファイル編集は絶対にしない**（レボの大原則）
- PR はユーザーが明示的に依頼した時だけ
