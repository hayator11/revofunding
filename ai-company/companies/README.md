# 子会社（サブカンパニー）一覧

各プロジェクトを、それぞれ独立した AI Company（社長＋部署）として運営する。
つばさ本社が発注し、各社の社長が内部に割り振り、成果を本社へ返す。

## 共通ルール（全子会社）
- 社長は必ず「発注受領 → 割り振り → 統合 → DoD確認 → 本社へ報告」を回す
- ネガティブ表現は使わない
- 外部公開・実投稿・PR は hayator の確認を挟む
- 各社の大原則は各 `company.md` に記載
