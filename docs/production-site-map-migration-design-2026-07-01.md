# 本番サイト移行設計 2026-07-01

## 目的

`site-map.html` に整理した新しいページ群を、本番サイトの正式導線として採用する。
既存ページは記録として残しつつ、利用者が迷わないようにトップページ、参加入口、全体構造、各一覧ページを統合する。

## 基本方針

- 本番トップは `https://revofunding.onokun.com/` とする。
- ドメイン名に `revofunding` が含まれているため、本番URLで `/revofunding/...` は使わない。
- 下層ページの本番URLは `/...` に統一する。
- 旧トップや旧紹介ページは削除せず、必要に応じて新ページへの案内・転送ページとして残す。
- 上部メニューに全ページを横並びで置かない。
- 常時表示は主要導線に絞り、詳細ページ群は `全体メニュー` にまとめる。
- `サイトマップ` は内部確認だけでなく、利用者が全ページを確認できる正式ページとして残す。

## トップメニュー設計

常時表示:

- プロジェクトを探す
- 応援で参加する
- 挑戦をはじめる
- レボアート
- 全体メニュー

`全体メニュー` 内:

- 全体構造
- プロジェクト紹介
- スパーク一覧
- バッチスパーカー
- ブースト一覧
- レボアート一覧
- 認定アーティスト
- サイトマップ

理由:

- 上部メニューに全ページを並べると、PCでもスマホでも詰まりやすい。
- 利用者の主な行動は「探す」「参加する」「挑戦を始める」「レボアートを見る」に集約できる。
- 一覧、詳細、Lab系ページは必要な人が `全体メニュー` から辿れる構成にする。

## サイトマップの役割

`/site-map.html` は以下を担う。

- 新しく増えたページ群の正式入口
- 運営確認用の全体リスト
- 利用者が迷ったときの案内
- 本番移行後のリンク抜け確認の基準

今後ページを追加する場合は、まずサイトマップへ追加し、その後に `全体メニュー` へ入れるか判断する。

## 移行手順

1. `index.html` を本番トップとして確定する。
2. `site-map.html` に掲載されているページを正式ページとして扱う。
3. 上部メニューを全ページで統一する。
4. 旧ページは削除せず、記録または新ページへの案内として残す。
5. `sitemap.xml` に正式ページを追加する。
6. `02_GITHUB_UPLOAD/` に本番反映用ファイルを同期する。
7. `02_GITHUB_UPLOAD/` では ``, `components/`, `data/`, `tokens/`, `assets/` をルート直下に置き、`revofunding/` 階層は公開対象に含めない。
8. ローカル確認URLでトップ、参加入口、プロジェクト紹介、サイトマップ、主要一覧を確認する。
9. 本番反映後、外部リンクと旧URL導線を確認する。

## 確認項目

- トップメニューがPCで横に詰まりすぎていない。
- スマホではメニューが横スクロールまたは折り返しで破綻しない。
- `全体メニュー` がヘッダーや地図の下に隠れない。
- `site-map.html` からすべての主要ページへ移動できる。
- `revolist-projects.html` の外部リンクが正しい。
- `sitemap.xml` に本番公開ページが含まれている。
- `02_GITHUB_UPLOAD/` に最新ファイルが同期されている。
